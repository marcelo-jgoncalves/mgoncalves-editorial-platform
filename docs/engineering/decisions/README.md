# Decisions

Armazena decisões arquiteturais e técnicas atualmente válidas, preferencialmente no formato ADR.

Uma decisão nível 6 de `docs/engineering/standards/change-risk-scale.md` exige um ADR aqui, além do protocolo de debate Claude↔Codex (`CLAUDE.md` §11). Estrutura mínima de um ADR: contexto, decisão, alternativas consideradas, consequências, nota final do protocolo (se aplicável).
